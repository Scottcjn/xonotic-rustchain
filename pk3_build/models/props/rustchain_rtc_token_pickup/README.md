# RustChain RTC Token Pickup prop

Original low-poly set-dressing prop for the Xonotic RustChain Arena prop bounty #14015:
https://github.com/Scottcjn/rustchain-bounties/issues/14015

## Package

| File | Purpose |
| --- | --- |
| `rustchain_rtc_token_pickup.iqm` | Static IQM model written directly from deterministic procedural geometry |
| `rustchain_rtc_token_pickup_0.skin` | DarkPlaces/Xonotic material-to-texture mapping |
| `rtc_token_pickup_gold.tga` | 256x256 RTC coin face texture |
| `rtc_token_pickup_edge.tga` | 256x256 darker coin rim texture |
| `rtc_token_pickup_glow.tga` | 256x256 orange/cyan pickup glow texture |
| `rtc_token_pickup_base.tga` | 256x256 dark metal pedestal texture |
| `rustchain_rtc_token_pickup_preview.png` | Preview render and texture swatches |
| `rustchain_rtc_token_pickup_source.obj` | Reproducible source mesh generated by the Python script |
| `rustchain_rtc_token_pickup_source.mtl` | Source material table for the generated OBJ mesh |

## Design

The model implements the **RTC token pickup** wishlist item. It is a compact
pickup-style arena prop with:

- floating RTC coin disk
- dark metal pedestal
- rotating-style lower glow ring
- four orange pickup pylons
- cyan/gold accent rails

The geometry is procedural and original. It does not embed external meshes,
samples, textures, or AI-generated model files.

## Regeneration

From the repository root:

```powershell
python tools/generate_rustchain_rtc_token_pickup_prop.py
```

The script writes the OBJ/MTL source, TGA textures, PNG preview, README,
LICENSE, skin file, and static IQM v2 model. It does not require Blender or
the bundled IQM executable.
