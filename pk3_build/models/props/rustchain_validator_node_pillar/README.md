# RustChain Validator Node Pillar prop

Original low-poly set-dressing prop for the Xonotic RustChain Arena prop bounty:
https://github.com/Scottcjn/rustchain-bounties/issues/14015

## Package

| File | Purpose |
| --- | --- |
| `rustchain_validator_node_pillar.iqm` | Static IQM model written directly from deterministic procedural geometry |
| `rustchain_validator_node_pillar_0.skin` | DarkPlaces/Xonotic material-to-texture mapping |
| `validator_node_pillar_metal.tga` | 256x256 panel metal diffuse texture |
| `validator_node_pillar_gold.tga` | 256x256 RTC trim and coin texture |
| `validator_node_pillar_glow.tga` | 256x256 emissive orange/cyan status-strip texture |
| `validator_node_pillar_glass.tga` | 256x256 holographic blue glass texture |
| `rustchain_validator_node_pillar_preview.png` | Preview render and texture swatches |
| `rustchain_validator_node_pillar_source.obj` | Reproducible source mesh generated by the Python script |
| `rustchain_validator_node_pillar_source.mtl` | Source material table for the generated OBJ mesh |

## Design

The model implements the **Validator node pillar / capture point** wishlist item.
It is a compact arena prop with:

- octagonal armored base
- vertical validator core
- four glowing consensus strips
- gold RTC top token
- low-poly top cap and corner rails

The geometry is procedural and original. It does not embed external meshes,
samples, textures, or AI-generated model files.

## Regeneration

From the repository root:

```powershell
python tools/generate_rustchain_validator_node_pillar_prop.py
```

The script writes the OBJ/MTL source, TGA textures, PNG preview, README,
LICENSE, skin file, and static IQM v2 model. It does not require Blender or
the bundled IQM executable.
