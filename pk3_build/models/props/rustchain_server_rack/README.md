# RustChain Server Rack / Validator Node Prop

Original low-poly prop for Xonotic RustChain Arena bounty #14015.

## Contents
- `rustchain_server_rack.iqm` — converted IQM mesh, low-poly static prop.
- `rustchain_server_rack.obj` + `.mtl` — editable source mesh.
- `textures/*.tga` — power-of-two texture set.
- `rustchain_server_rack.skin` — material mapping hint.
- `preview.png` — generated preview render.

## Integration
Suggested path: `pk3_build/models/props/rustchain_server_rack/`.
Place as set dressing near spawn alcoves, capture points, or antiquity vault corridors. The front LED trays read as validator activity without adding gameplay obstruction; the model footprint is approx. 1.2 x 0.4 x 2.2 units before mapper scale.
