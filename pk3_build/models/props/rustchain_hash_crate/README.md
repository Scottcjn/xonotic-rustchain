# RustChain Hash Crate prop

Original low-poly set-dressing prop for the Xonotic RustChain Arena prop bounty #14015:
https://github.com/Scottcjn/rustchain-bounties/issues/14015

## Package

| File | Purpose |
| --- | --- |
| `rustchain_hash_crate.iqm` | Static IQM model written directly from deterministic procedural geometry |
| `rustchain_hash_crate_0.skin` | DarkPlaces/Xonotic material-to-texture mapping |
| `hash_crate_iron.tga` | 256x256 dark iron frame texture |
| `hash_crate_panels.tga` | 256x256 crate side panel texture |
| `hash_crate_glow.tga` | 256x256 cyan hash-core glow texture |
| `hash_crate_warning.tga` | 256x256 orange hazard-stripe texture |
| `rustchain_hash_crate_preview.png` | Preview render and texture swatches |
| `rustchain_hash_crate_source.obj` | Reproducible source mesh generated by the Python script |
| `rustchain_hash_crate_source.mtl` | Source material table for the generated OBJ mesh |

## Design

The model implements the **hash crate** wishlist item. It is a compact arena
supply crate with a dark metal frame, reinforced panel faces, cyan hash-core
windows, orange hazard corner plates, and a raised top plate marked HASH.

The geometry is procedural and original. It does not embed external meshes,
samples, textures, or AI-generated model files.

## Regeneration

From the repository root:

```powershell
python tools/generate_rustchain_hash_crate_prop.py
```

The script writes the OBJ/MTL source, TGA textures, PNG preview, README,
LICENSE, skin file, and static IQM v2 model. It does not require Blender or
the bundled IQM executable.
