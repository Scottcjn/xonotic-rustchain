# Xonotic RustChain Arena — Weapon SFX Set

Submission for RustChain bounties issue #293: original weapon sound effects for the Xonotic RustChain Arena.

## Contents
- `validator_pistol_charge.wav` and `validator_pistol_discharge.wav`
- `forker_shotgun_pump.wav` and `forker_shotgun_dual_blast.wav`
- `hashcannon_windup.wav` and `hashcannon_beam.wav`
- `mempool_grenade_cluster.wav` and `mempool_grenade_detonation.wav`
- `double_spend_smgs_burst.wav`
- `manifest.json` with durations and SHA-256 per WAV

## Design notes
These are procedurally generated, original 44.1 kHz mono WAV assets intended as lightweight placeholders or direct game-ready sounds. The palette is deliberately digital/arcade: rising validator charge tones, mechanical/noisy forker pump + dual blast, high-energy hashcannon windup/beam, mempool cluster clicks/detonation, and rapid double-spend transaction clicks.
