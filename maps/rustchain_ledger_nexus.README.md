# RustChain Ledger Nexus

Symmetric DM/CA arena for Xonotic RustChain. Central ledger core with vertical validator shafts and mempool flanks designed for aggressive flow and blood-economy gameplay.

## Features
- Symmetric 4-spawn layout for balanced DM/CA
- Central elevated platform with health medium reward
- Flanking corridors with weapon placement (shotgun/machinegun)
- Vertical sightlines through validator shafts
- RustChain/blockchain thematic elements
